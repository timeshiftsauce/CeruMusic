# 版本与兼容

**澜音 2.0 开始使用 v2 插件。澜音 1.14.1 仍使用 v1。** 软件版本和插件清单中的协议版本不是同一个概念。

## 选择对应的文档

| 使用环境 | 对应资料 |
| --- | --- |
| 澜音 2.0 的 v2 插件 | 本指南，从[运行插件](./quick-start)开始 |
| 澜音 1.14.1 的 v1 插件 | [v1 开发指南](/guide/CeruMusicPluginDev) |
| 将已有 v1 插件改为 v2 | [迁移指南](./migration)，不能只改清单版本号 |

v2 成品不能直接安装到 v1 宿主中。上线前测试请使用支持 v2 的澜音 2.0 开发构建；开发工作台可独立运行。

## 清单中的版本各自表示什么？

| 字段 | 示例 | 用途 |
| --- | --- | --- |
| `manifestVersion` | `2` | 清单格式 |
| `engines.hostApi` | `"^2.0.0"` | 要求宿主提供的插件 API 协议 |
| `engines.logicRuntime` | `"ceru-js@1"` | 后台代码的运行环境 |
| `engines.uiSchema` | `"^1.0.0"` | 声明式界面协议 |
| `version` | `"0.1.0"` | 由插件作者维护的插件自身版本 |

新工程保留脚手架生成的协议声明即可。不要根据软件版本猜测或替换这些字段。

## 工作台和桌面

工作台适合调试命令、搜索和页面，但不会提供所有桌面服务。最终发布前仍需在澜音 2.0 中安装同一份成品，检查用户入口、权限、持久存储和播放。具体差异见[宿主支持表](./host-services)。

开发依赖的安装方式见[开发环境与依赖](./sdk-upgrade)。
