# 澜音 v3 插件开发文档审校记录

审校日期为 2026-11-21。文档以清单 v3、CLI / SDK / Core 3.0.0、支持双运行时的澜音桌面 2.5.0 测试构建为基线。开发路线采用 npm、TypeScript 和 Vue，隔离 HTML、原生视图、旧插件迁移另有入口。完整目录与各页学习步骤见[编写方案](./plugin-v3-writing-plan.md)。

## 需要保留的验证边界

- “十分钟”是工具就绪后的教学目标。已经走通首次运行与热重载流程；尚无独立新手计时记录。首次下载依赖的时间依网络而定。
- 公开测试构建的长期下载入口和正式版发布日期，随维护者的发布安排更新。教程给出本地构建与校验路线。
- 系统挂起、恢复、锁屏、解锁依赖操作系统实际通知。本轮没有在物理设备上逐一执行。第三方平台凭据与局域网设备同样需要在对应目标环境验收，模拟场景只用于验证插件控制流。
- 升级 SDK 或 Core 时重新构建参考页，核对索引、字段与权限，重跑示例和浏览器检查。宿主支持情况仍应在目标桌面验证。构建工具提示存在超过 500 kB 的前端分块，当前未测量公网首屏性能。
