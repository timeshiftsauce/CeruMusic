# v2 插件文档重写 TODO

## 目标与写作规则

面向会基本 JavaScript、第一次开发澜音插件的人。教程必须让读者在自己的工程中逐步完成一个功能，并知道代码为什么能运行。

- 每节交代前置工程、修改文件、完整改法、运行位置、预期结果和常见失败。
- 同一条入门路线持续使用同一个工程，不在 Vue、普通 DOM、完成版之间无提示切换。
- 首次使用概念时解释它的用途和调用关系；参数全集放参考文档。
- 明确代码块是完整文件、局部替换还是只读示意；必做步骤不依赖未定义的辅助函数。
- 工作台与桌面分别说明入口和验证方法；下载成品只用于对照。
- 版本核验、旧协议迁移、宿主内部实现不插入新手操作步骤。
- 产品边界：澜音 2.0 开始使用 v2 插件；1.14.1 仍使用 v1。
- v2 尚未上线，按用户首次接触的开发环境组织内容，不讲 SDK/CLI 内部版本演进和修复历史。安装命令使用当前工具，具体依赖由工程锁文件记录。
- 平台和音质命名提供推荐约定，不作为强制枚举或必备能力；允许自定义标识，音质只声明实际支持的档位。
- 全部教程不提及“聆澜音源”；配套示例和图示同样遵守，使用中性的示例名称。已检索当前教程源码和五个下载 ZIP，无该名称；历史教程两处“澜音源”也改为“示例音源插件”。
- CLI 和模板以实际源码及生成结果为依据，不根据文档互相推断。
